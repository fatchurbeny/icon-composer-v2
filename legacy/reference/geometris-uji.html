Gaya Geometris garis · uji cara kerja

Satu warna, sudut tajam, celah knockout, bentuk dasar buatan sendiri (bukan Lucide). Klik ikon untuk membukanya di editor mini di bawah.

1. Cara kerja

Pustaka bentuk bersudutSetiap bentuk digambar dari garis lurus di grid 48, plus siluet tertutup untuk pemotong celah.
Template komposisiMenentukan peran dan posisi lapisan: alas, objek, penanda, unsur ketiga, dekorasi.
Celah knockoutSetiap lapisan dipotong oleh siluet lapisan di atasnya, diperlebar sebesar celah.
Patokan setTebal garis, celah, ujung garis, dan warna sama untuk semua ikon, jadi pack tetap konsisten.

2. Empat template komposisi

AlasObjekPenandaUnsur ketigaDekorasi

Kiri: lapisan diwarnai menurut perannya. Kanan: hasil akhir satu warna.

3. Contoh pack (12 ikon)

Kombinasi sengaja dibuat berbeda dari referensi, supaya hasilnya tetap orisinal.

4. Editor mini

Pilih template dan bentuk, atur patokan set. Semua ikon di atas ikut berubah saat patokan set diubah.
